# Guided Learning Workflow

- Work in small, clearly scoped milestones. Do not jump ahead to later features.
- Explain concepts and decisions in plain English, introducing technical terms when they are useful.
- Add meaningful tests for the behavior in each milestone, including relevant boundary and failure cases.
- Run the requested checks and report only commands that were actually run and results that were actually observed.
- Keep the learner involved: explain the goal of each exercise and leave implementation practice for the learner when asked.
